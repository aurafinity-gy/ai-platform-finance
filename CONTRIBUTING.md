# Contributing

This repository is the source of truth for the Finance bounded context.

## Working Rules

- Use short-lived feature branches.
- Keep commits small and focused.
- Prefer imperative commit messages.
- Do not commit secrets or environment-specific credentials.

## Release Guidance

- `main` is the integration branch.
- The first stable tag should be `v0.1.0`.
- Cut tags only from a clean, validated `main`.
